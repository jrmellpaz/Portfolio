This prototype is a style and occasion-based outfit recommendation system using machine learning classification for personalized fashion suggestions. It uses the <a href="https://www.kaggle.com/datasets/paramaggarwal/fashion-product-images-dataset" target="_blank" rel="noopener noreferrer">Fashion Products dataset</a>, which has more than 40,000 images that can be used for recommendations.

This prototype was our final project for our Machine Learning course. I took care of the model training, the API endpoints, and the frontend.
