CLAUDE (Computing Living Affodability Using Data Exploration) is an interactive data platform built to answer how many days of minimum wage an average household need to afford a basic food basket. The dashboard is powered by raw government data from January 2018 onwards, combining regional prices, wages, and economic indicators. With this tool, users can track affordability across different Philippine regions, view trends over time, and create customizable food basket from select items.

Built as a project for my Data Analytics class, I handled the end-to-end development of this platform, including the raw data processing and the final frontend visualization and AI integration. The architecture is divided into three layers:

<ol class="list-decimal ps-5 space-y-4">
<li>Data Pipeline (Python): I created a pipeline that accepts raw spreadsheet and CSV data as input and clean them. This standardizes the names of the 17 regions and merges minimum wage, household sizes, consumer price indices, and prices for 49 different commodities into a time-series.</li>

<li>Statistical Modeling (Python): To determine the factors that drive food affordability, I fit an Ordinary Least Squares regression model to the dataset. The model successfully identified that daily wages and household size are the strongest drivers.</li>

<li>Interactive Dashboard (TypeScript & React): I built the frontend interface to instantly compute affordability metrics based on various parameters. The dashboard features a choropleth map for regional comparisons, chart-based trend tracking, and a dynamic basket editor where users can adjust food quantities.</li>
</ol>
